# توقيع مثبت Windows

يستخدم CI توقيعًا اختيارياً للمثبت بعد بنائه.

## الأسرار المطلوبة

أضف في إعدادات مستودع GitHub سرين:

- `WINDOWS_CERT_PFX_BASE64`: محتوى شهادة `.pfx` بعد تحويلها إلى Base64.
- `WINDOWS_CERT_PASSWORD`: كلمة مرور الشهادة.

تُفك الشهادة مؤقتاً داخل مهمة CI، ويُستخدم `signtool` مع SHA-256 وخادم توقيت، ثم تُحذف من العامل.

## عند عدم وجود الأسرار

يكمل CI البناء ويرفع المثبت وبصمته، ويطبع الرسالة: **الـ installer غير موقّع**. سيظهر تحذير SmartScreen للمستخدمين حتى يتم توقيع المثبت بشهادة موثوقة.
