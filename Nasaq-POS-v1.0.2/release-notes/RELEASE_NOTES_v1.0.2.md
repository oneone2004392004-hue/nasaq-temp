# سجل إصدار نسق لنقاط البيع (Nasaq POS Release Notes)
## الإصدار: v1.0.2 (Production Release)
**تاريخ الإصدار:** سبتمبر 2026

### المميزات الرئيسية (Key Highlights)
- **نظام سطح مكتب متكامل**: مبني على Tauri v2 ومحرك SQLite المحلي للعمل على أجهزة Windows 10/11 بدون أي اعتمادية على الإنترنت.
- **تصميم مخصص للمطاعم والكافيهات المصرية**:
  - عملة الجنيه المصري (EGP / ج.م) مع تخزين مالي دقيق بالقروش (Minor Units).
  - توافق كامل مع نسب الضريبة المصرية (14% أو تخصيص يدوي أو إعفاء كامل للمنشآت غير المسجلة).
  - دعم أنماط الخدمة الثلاثة: صالة (طاولات)، تيك أواي، وتوصيل منازل (دليفري).
- **أمان مالي ورقابي صارم**:
  - عمليات سداد ومعاملات ذرية (Atomic Transactions) تمنع السداد المزدوج أو التجزئة المالية.
  - إغلاق ومطابقة الورديات وحساب عجز/زيادة الخزينة بدقة مئوية.
- **جسر طباعة حرارية أصيل**:
  - طباعة مباشرة عبر Windows Spooler وطابعات الشبكة TCP 9100.
  - معالجة النصوص وتشكيل الحروف العربية ذاتياً.
  - فتح آلي مشروط لدرج النقدية عند السداد النقدي فقط.
- **حماية البيانات واستعادتها**:
  - نظام نسخ احتياطي محلي مع فحوصات سلامة مدمجة `PRAGMA integrity_check`.
  - آلية رجوع تلقائي (Rollback) تمنع تلف البيانات أثناء الاستعادة.
