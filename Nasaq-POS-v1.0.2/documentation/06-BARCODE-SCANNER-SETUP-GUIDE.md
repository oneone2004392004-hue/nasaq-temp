# دليل قارئ الباركود (Barcode Scanner Setup Guide)

## آلية التشغيل (Plug & Play)
- يدعم النظام جميع أجهزة قراءة الباركود القياسية عبر USB بتنسيق HID Keyboard Wedge (المحاكي للوحة المفاتيح).
- لا يتطلب أي برامج تشغيل خاصة أو SDKs مغلقة.
- يدعم قراءة الباركود متبوعاً بحرف الإدخال (Enter / CR LF).

## الحماية والتشغيل
- البحث فوري ومحمي بمعدل استجابة يقل عن 1 مللي ثانية.
- في حال قراءة باركود غير موجود في قاعدة البيانات، يصدر النظام تنبيهاً مرئياً واضحاً دون إنشاء أي منتجات وهمية.
- المنتجات المعطلة (`is_active = 0`) محظورة تماماً من البيع عبر الباركود أو القائمة.
