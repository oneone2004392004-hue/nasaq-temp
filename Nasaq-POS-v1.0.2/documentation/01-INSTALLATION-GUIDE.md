# دليل تثبيت نظام نسق لنقاط البيع (Nasaq POS v1.0.2)

## متطلبات التشغيل (System Requirements)
- **نظام التشغيل**: Windows 10 (Build 19041+) أو Windows 11 (64-bit).
- **الذاكرة العشوائية (RAM)**: 4GB كحد أدنى (يوصى بـ 8GB).
- **المساحة التخزينية**: 200MB للبرنامج، ويوصى بتوفر 2GB لقاعدة البيانات والنسخ الاحتياطية.
- **مكونات النظام**: Microsoft Edge WebView2 Runtime (مدمج افتراضياً في Windows 10/11 الحديث).
- **الشاشة**: دقة عرض 1366x768 كحد أدنى (يدعم 1280x720 و 1920x1080 بدقة كاملة).

## خطوات التثبيت (Installation Steps)
1. تشغيل ملف التثبيت `NasaqPOS_1.0.2_x64-setup.exe`.
2. يتم التثبيت في المسار الافتراضي للمستخدم (`%LOCALAPPDATA%\Programs\NasaqPOS`) دون الحاجة لصلاحيات مدير النظام (No UAC required).
3. يتم إنشاء اختصار على سطح المكتب وقائمة ابدأ باسم "نسق لنقاط البيع".
4. يتم إنشاء مسار قاعدة البيانات تلقائياً في: `%APPDATA%\com.nasaq.pos\data\nasaq.db`.
5. يتم إنشاء مسار النسخ الاحتياطية التلقائية في: `%APPDATA%\com.nasaq.pos\backups\`.
