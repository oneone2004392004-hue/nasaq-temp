# دليل إعداد درج النقدية (Cash Drawer Setup Guide)

## آلية العمل والربط
- يتم ربط درج النقدية عبر كابل RJ11 / RJ12 المتصل بمنفذ درج النقدية في طابعة الإيصالات الحرارية (DK Port).
- يقوم النظام بإرسال نبضة الفتح القياسية ESC/POS (`ESC p 0 25 250` للمنفذ الأول أو `ESC p 1 25 250` للمنفذ الثاني).

## القواعد المالية والتشغيلية
1. **الفتح التلقائي عند الدفع النقدي**: يفتح الدرج تلقائياً فقط عند تسجيل عملية دفع نقدي (CASH) أو دفع مجزأ يحتوي على جزء نقدي.
2. **منع الفتح عند الدفع بالبطاقة**: لا يتم إرسال نبضة فتح الدرج إذا كانت الفاتورة مسددة بالكامل عبر البطاقة البنكية (CARD).
3. **الفتح اليدوي المقيد**: الفتح اليدوي للدرج (عبر زر الشاشة أو F12) مقيد بصلاحية المستخدم (`pos.open_cash_drawer`) ويسجل فورياً في سجل التدقيق المالي والرقابي (Audit Log).
