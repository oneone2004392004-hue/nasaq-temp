# دليل الإعداد والتشغيل الأول (First Run Setup Guide)

## شاشة الإعداد الأولي (First Run Wizard)
عند فتح النظام للمرة الأولى على جهاز جديد:
1. تظهر شاشة تهيئة مدير النظام (Initial Administrator Setup).
2. إدخال اسم المستخدم وكلمة المرور لحساب المدير (كلمة المرور مشفرة بواسطة bcrypt مع salt rounds = 10).
3. إدخال بيانات المنشأة:
   - اسم المطعم / الكافيه (مثال: مطعم نسق للمأكولات).
   - رقم الهاتف والعنوان.
   - الرقم الضريبي والسجل التجاري (اختياري حسب التسجيل القانوني للمنشأة).
   - نسبة الضريبة الافتراضية (افتراضياً 14% ضريبة القيمة المضافة المصرية أو 0% للمنشآت غير الخاضعة).
4. الضغط على "إتمام الإعداد وبدء العمل" لتفعيل النظام وإنشاء الجداول وتجهيز وردية العمل الأولى.
