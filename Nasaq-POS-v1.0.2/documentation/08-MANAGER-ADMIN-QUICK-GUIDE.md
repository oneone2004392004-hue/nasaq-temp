# دليل الإدارة والمشرفين (Manager & Admin Guide)

## الصلاحيات والأمان
- نظام تحكم بالوصول قائم على الأدوار (RBAC) مع 4 أدوار قياسية: مدير النظام (Admin)، المشرف (Manager)، الكاشير (Cashier)، والمحاسب (Accountant).
- قفل الحساب التلقائي بعد 5 محاولات دخول خاطئة لحماية النظام من التخمين.
- إمكانية قفل الشاشة السريع لحماية نقطة البيع أثناء مغادرة الكاشير المؤقتة.

## التقارير المالية والتحليلية
- تقرير مبيعات يومي وشهري وحسب الوردية.
- تقرير تفصيلي لضريبة القيمة المضافة (المبيعات الخاضعة والمعفاة وقيمة الضريبة).
- تقرير حركة الخزينة والمصروفات.
- تقرير أداء الأصناف والمجموعات الأكثر مبيعاً.
- سجل تدقيق غير قابل للتعديل (Audit Log) يسجل كافة العمليات الحساسة بتوقيت النظام واسم المستخدم.
