# دليل إعداد طابعات الإيصالات والمطبخ (Thermal & Kitchen Printer Guide)

## أنواع الربط المدعومة (Supported Connections)
1. **طابعات Windows Spooler (USB / Virtual COM)**:
   - يتم التعرف التلقائي على الطابعات المثبتة عبر خدمة Windows Print Spooler (`winspool.drv`).
   - إرسال أوامر خام ESC/POS RAW مباشرة لرأس الطباعة.
2. **طابعات الشبكة (Network / Ethernet / Wi-Fi)**:
   - الربط المباشر عبر منفذ TCP RAW 9100.
   - مهلة اتصال محددة (Timeout) تمنع تجميد النظام في حال انقطاع كابل الشبكة.

## ضبط المقاسات وتشكيل اللغة العربية
- يدعم النظام مقاسات ورق 80 مم (48 حرفاً في السطر) و 58 مم (32 حرفاً في السطر).
- مدمج محرك تشكيل ومعالجة اتجاه اللغة العربية (Arabic Reshaping & BiDi RTL) لدعم كافة الطابعات الحرارية بدون الحاجة لخطوط عربية محملة في ذاكرة الطابعة.
- فصل تام بين إيصال العميل وتذكرة المطبخ (تذكرة المطبخ تركز على الأصناف والخيارات بدون إجماليات مالية).
